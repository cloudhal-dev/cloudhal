# Cloudhal brand

The mark is the **Lens**: a calm, always-on eye in Cloudhal orange. It stands for an agent that watches, previews and waits for a person before anything goes live.

| File | Use |
|---|---|
| `mark.svg` | The mark in colour. Favicons, avatars, app icons |
| `mark-mono.svg` | One colour (`currentColor`), for single-colour print, stamps and embossing |
| `wordmark-light.svg`, `wordmark-dark.svg` | Mark and name, for light and dark backgrounds |
| `favicon.ico` (16, 32, 48), `apple-touch-icon.png` (180), `mark-512.png` | Raster sizes |
| `social-preview.html` → `social-preview.png` | The 1280×640 card for GitHub and link previews |

## Colours

| Name | Hex | Role |
|---|---|---|
| Cloudhal orange | `#b4441f` | The tile; accent on light backgrounds |
| Ember | `#5a200c` | The lens body |
| Glow | `#ee8a64` | The core; accent on dark backgrounds |
| Halo | `#f6c3ad` | The ring |
| Spark | `#fff4ec` | The pupil |
| Ink | `#1c1c1a` / `#141413` | Text and dark backgrounds |

## Rules

- Keep the mark square with its rounded corners (radius 14/64). Don't recolour the lens, add a frame, bevel or reflection, or turn it red.
- Clear space around the mark: at least a quarter of its width.
- Smallest size: 16 px.
- The name is written **Cloudhal**, one word, capital C only.

Rendering the PNGs: open the SVG or HTML in headless Chrome at the target size (see the commit that added this folder).
