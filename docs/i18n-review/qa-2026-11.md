# Machine-draft QA pass, November 2026 (#112)

An AI quality pass over the machine-drafted Studio strings in all 18 non-English languages, before human review. It changes **no** language's `reviewed` flag: every language except English and Turkish stays `reviewed: false` until a person who speaks it reviews it. Terms: [glossary](../guides/translations-weblate.md#6-glossary-of-coined-terms).

## Scope

The same 494 keys in each of the 18 languages (8892 drafts):

| Group | Keys |
|---|---|
| core: setup-link sign-up text and the MCP OAuth access row | 3 |
| core: tool labels, error codes, collection list and navigation from #112 | 38 |
| `build`: the playground hint (changed after #112) | 1 |
| `collections` namespace | 81 |
| `connectedAgents` namespace | 42 |
| `fields` namespace | 154 |
| `listings` namespace | 131 |
| `oauthConsent` namespace (consent screen) | 29 |
| `status` (the renderer's status pages, read by site visitors) | 15 |

## How it was checked

1. **Automatic**, per language (a script over the exchange JSON): the same placeholders as English and the same kinds, every select value, every CLDR plural category of the language (`Intl.PluralRules`), `#` kept inside plurals, text identical to English, English words left in non-Latin text, and short labels (≤ 24 characters in English) more than 2.5 times longer.
2. **Semantic**: every draft back-translated to English and compared with the source, the security-relevant strings (consent screen, the identity labels, the look-alike and loopback warnings, the setup-link text, error messages, status pages) word by word; plus terminology against the glossary and the file's own register.
3. **Fixes** only for clear errors: changed meaning, a softened security statement, a dropped "you" or "never", leftover English, a term or register that differs from the rest of the language's Studio, grammar a native speaker would call wrong. Applied through `.i18n/` and `pnpm i18n:import`. Stylistic choices are listed below as review items for the language's reviewers.

## Automatic checks

No language has an ICU error, a lost or extra placeholder, a missing select value, a missing plural category or a misplaced `#` (Turkish writes `{count, number}` where its nouns stay singular, which the translate skill allows). What the script flagged and was left as it is:

- **Identical to English**: cognates that are the normal word (fr *Collections*, *Date*, *Type*, *Options*; nl *Type*, *Label*, *Product*; de *Name*, *Text*, *Link*; id *Label*, *Edit…*; it/pt-BR/pl/nl *Link*), and `Site: {property}`.
- **English left in non-Latin text**: product and technical names (sitemap.xml, file paths, `CLOUDHAL_MCP_DCR`, `--base-url`, `entry.fields`, `startsAt`, Workers AI, Google's *Rich Results Test*) and the names of buttons in Claude and MCP Inspector (*Settings*, *Connectors*, *Authenticate*), which those apps may show in English. ru and uk also wrote "sitemap" in a label; fixed to their own word.
- **Length**: no short label grew past 2.5× in a way that breaks a layout; the longest are column headers and buttons such as ru *Последнее использование* (Last used), uk *Попередній перегляд* (Preview), hi *अस्वीकार करें* (Deny), de *Rückgängig machen* (Revert). Left for reviewers.
