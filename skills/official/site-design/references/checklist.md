# Before handing over

- [ ] The page follows the site's design rules (or the theme's, where the site has none).
- [ ] One level-1 heading; level 2 per section; no skipped levels.
- [ ] No placeholder text, `#` links or repeated images; every image has descriptive alt text.
- [ ] Tones and layouts alternate; no three identical sections in a row.
- [ ] Counts match the real content.
- [ ] Rendered at 1440 and 390 px: no horizontal scroll, nothing cramped or empty, text readable, buttons large enough to tap.
- [ ] Interactive parts work with their data bound, and the page still makes sense before anything is clicked.
- [ ] A snapshot labelled "Design: <page>" exists and the person has the preview URL.
