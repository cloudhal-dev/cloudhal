Studio: a theme menu in the top bar (light, dark or the system's scheme, remembered per browser and applied before first paint; also in the user menu and the command palette). The shell now fits the visible viewport, so reaching the end of the sidebar or a page no longer scrolls the whole document on phones (half-hidden top bar, empty strip below). The settings "On this page" list highlights the last section at the end of the page and keeps a clicked section selected. The sidebar header lines up with the top bar, list pages show their title icon consistently, and cards no longer widen past a 320 px screen when they hold a long id. The collapse button no longer makes the sidebar flicker under the cursor; the user menu moved to an avatar at the end of the top bar (always reachable, also when the sidebar is collapsed); on phones the navigation sheet closes once a page is chosen; and long lists (Snapshots) no longer leave an empty strip after the end of the page.
