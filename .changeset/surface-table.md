Surfaces show tables (RFC-0022 22d).
- **`Table`:** rows from the surface's data, up to 8 columns with locale formatting (number, currency, percent, date), a highlighted row and optional stripes.
- **HTML:** a real `<table>` with a caption and column headers; rows become label–value cards on phones.
- **Inputs:** fields in one grid row now stay aligned when one has help text.
