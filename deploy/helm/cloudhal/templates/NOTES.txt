Create the Owner account with the setup link from the logs, the token in place of the placeholder:
  kubectl -n {{ .Release.Namespace }} logs {{ include "cloudhal.fullname" . }}-0 -c cloudhal | grep setup
  kubectl -n {{ .Release.Namespace }} get secret {{ include "cloudhal.secretName" . }} -o jsonpath='{.data.CLOUDHAL_SETUP_TOKEN}' | base64 -d

The Secret {{ include "cloudhal.secretName" . }} holds the site id and the cluster key: keep a copy;
it is not deleted with the release (helm.sh/resource-policy: keep).
