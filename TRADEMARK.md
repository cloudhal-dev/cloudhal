# Cloudhal Trademark Guidelines

"Cloudhal" and the Cloudhal logo are trademarks of the Cloudhal project. The Apache License 2.0 that covers the code does **not** grant permission to use these marks (see §6 of the license). These guidelines explain what you can do without asking.

## You may, without permission

- Say truthfully that your product or site is **built with Cloudhal**, **runs on Cloudhal**, or is **compatible with Cloudhal**.
- Use the name to refer to the project in articles, talks, tutorials and comparisons (nominative use).
- Redistribute **unmodified** official releases under their original name.
- Use the name in a package or repository name that clearly signals a third-party extension, e.g. `cloudhal-capability-newsletter`, `@yourorg/cloudhal-theme-dark`.

## Please do not

- Use "Cloudhal" as the name (or part of the name) of your own product, company, domain or hosted service, e.g. "Cloudhal Hosting", "cloudhal-cloud.example".
- Distribute **modified** versions under the Cloudhal name without clearly stating they are modified, or in a way that suggests they are official.
- Use the logo or name in a way that implies endorsement, partnership or official status.
- Use the marks on merchandise.

## Attribution

Where practical: "Cloudhal is a trademark of the Cloudhal project."

## Questions

Email **legal@cloudhal.com**. We are generous with permission for community uses; this document exists so that the open-source code can be forked freely while the name keeps meaning one thing.

_Modelled on the trademark guidelines of the Spring and OpenSearch projects._
